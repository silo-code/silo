# Keyboard shortcuts

The defaults. Every one of these can be changed on **Settings → Keyboard
Shortcuts**, where you can also bind any command that doesn't have a key yet
— each agent profile's **New Agent: …** command, for instance.

On Windows and Linux, read <kbd>⌘</kbd> as <kbd>Ctrl</kbd> and <kbd>⌥</kbd>
as <kbd>Alt</kbd>.

## Workspaces

| Action                        | Shortcut       |
| ----------------------------- | -------------- |
| New workspace (folder picker) | <kbd>⌘⇧N</kbd> |
| Next workspace                | <kbd>⌘`</kbd>  |
| Previous workspace            | <kbd>⌘⇧`</kbd> |

## Center tabs

| Action                           | Shortcut                        |
| -------------------------------- | ------------------------------- |
| New chat (default agent profile) | <kbd>⌘⌥I</kbd>                  |
| New terminal                     | <kbd>⌘T</kbd>                   |
| New file                         | <kbd>⌘N</kbd>                   |
| Open file…                       | <kbd>⌘O</kbd>                   |
| Save / Save as                   | <kbd>⌘S</kbd> / <kbd>⌘⇧S</kbd>  |
| Close tab                        | <kbd>⌘W</kbd>                   |
| Next / previous tab              | <kbd>⌘⌥→</kbd> / <kbd>⌘⌥←</kbd> |
| Next / previous split group      | <kbd>⌘⌥↓</kbd> / <kbd>⌘⌥↑</kbd> |
| Clear terminal                   | <kbd>⌘K</kbd>                   |

## Chat composer

| Action                | Shortcut                                                             |
| --------------------- | -------------------------------------------------------------------- |
| Send                  | <kbd>Enter</kbd>                                                     |
| New line              | <kbd>Shift+Enter</kbd>                                               |
| Slash-command palette | <kbd>/</kbd> at the start of the field                               |
| Pick a palette entry  | <kbd>↑</kbd> / <kbd>↓</kbd>, then <kbd>Tab</kbd> or <kbd>Enter</kbd> |
| Attach by drag        | hold <kbd>Shift</kbd> while dropping a file from Files               |

## Columns and focus

| Action                | Shortcut       |
| --------------------- | -------------- |
| Toggle left column    | <kbd>⌘⌥[</kbd> |
| Toggle right column   | <kbd>⌘⌥]</kbd> |
| Focus next region     | <kbd>⌘⌥.</kbd> |
| Focus previous region | <kbd>⌘⌥,</kbd> |
| Search in files       | <kbd>⌘⇧F</kbd> |

## App

| Action                | Shortcut                                      |
| --------------------- | --------------------------------------------- |
| Settings              | <kbd>⌘,</kbd>                                 |
| Zoom in / out / reset | <kbd>⌘=</kbd> / <kbd>⌘-</kbd> / <kbd>⌘0</kbd> |
| Reload window         | <kbd>⌘R</kbd>                                 |
